# Punk Ducali Festival Website

Sito statico HTML/CSS/JS pronto per GitHub + Vercel.

## Struttura

- `index.html`
- `style.css`
- `script.js`
- `assets/`
  - `gallery/`
  - `posters/`
  - `logos/`

## Deploy su Vercel

1. Carica tutta la cartella in una repo GitHub.
2. Importa la repo su Vercel.
3. Framework preset: **Other** / static site.
4. Output directory: lascia vuoto.
5. Deploy.

## Note

I video non sono caricati nel repo: usano thumbnail YouTube e link esterni, così il progetto resta leggero.
